# Личен профил сайт

Мини сайт, създаден с HTML, CSS и JavaScript, който представя моята лична информация, умения и интереси.

---

## 🧠 Функционалности

- **Смяна на фон**: бутон „Смени цвят на фона“ сменя произволно фоновия цвят на страницата.  
- **Интересен факт**: бутон „Покажи интересен факт“ изкарва изскачащ прозорец (alert) с произволен факт от предварително зададен списък.  
- **Отзивчив дизайн**: работи коректно на десктоп и мобилен изглед.

---

## 🛠 Технологии

- **HTML5** – семантична структура на страницата  
- **CSS3** – базово оформление, центриране и подреждане на елементи  
- **JavaScript** – функции, масиви, събития и манипулация на DOM

---
